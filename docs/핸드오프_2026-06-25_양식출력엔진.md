## 4. ⚠️ 미적용·주의

1. **0026은 미적용 상태.** 다음 **앱 재시작** 시 `migrate.ts`가 자동 적용한다.
   - **적용 검증법**: 앱 실행 → 문서BOM → **SP-02 검사및시험** 프로세스 열기 → `L-2100 인수검사성적서` 등 검사양식이 보이면 성공(이전엔 검사양식이 CP-03 생산에 잘못 있었음).
2. **마이그레이션 SQL에 `BEGIN/COMMIT` 금지.** `migrate.ts:51`이 각 마이그레이션을 `db.transaction()`으로 감싼다 → 중첩 트랜잭션 에러.
3. **마이그레이션은 앱 러너(재시작)로만 적용.** python-while-running 금지(라이브 DB 어긋남).
4. `_demo_output/`·`scripts/` probe류는 데모/탐색용 — 출하 전 정리 대상.

- **해결 과제**:
  - **체크박스**: `□ 시정/□ 예방`(s3)·발행구분(s5) 같은 건 값에 따라 해당 `□`→`■` 치환 로직 필요
  - **wrapText**: 긴 텍스트(부적합사항 등)는 셀 `alignment.wrapText=true` 줘야 안 잘림
  - **날짜 포맷**: `type=date` 셀 포맷 통일

### ▶ 2순위: 갭1 ③ — 앱 통합
- `form_fields`가 **B2100-01 등 5개만 정의**돼 있다(나머지 262 폼형은 "필드 미정의"). → **셀맵 CSV를 form_fields로 자동 시드**(마이그레이션 or 임포트). `label`=라벨, `cell`은 별도 매핑테이블(예 `form_cell_map`)에 저장.
- IPC 핸들러 `FORM_EXPORT_XLSX(submissionId)` 추가 → 위 ②엔진 호출 → 파일 경로 반환.
- 작성 화면(FormCanvas/드로어)에 **"공식 엑셀 출력" 버튼**.
- **분배엔진 연결**: 기존 `form_submissions.values_json`(s1~s10, h1~h4 등)의 field_key를 셀맵의 field_key와 매핑. 예: B1100-01 `h2`(작성일)↔셀맵 `작성일자`(E4). 이 연결표가 ②③의 다리.

### ▶ 3순위: 보강
- **셀맵 실패 38 폼형**(병합 있으나 라벨↔입력 인접 안 맞음): 별도 휴리스틱 or 수동.
- **격자표 14 + 대장·매트릭스 42**: 폼 모델 부적합 → 다른 출력 방식(행 반복) 설계.
- **미수집 27규정**(갭2의 E·M·D 양식): 위 ②엔진이 서면 그 규정 .xlsx에서 동일하게 추출·출력.

## 6. 핵심 설계 결정·발견

1. **양식은 최소 4유형**(form/대장/격자/매트릭스). 단일 휴리스틱으로 218개 자동화는 불가 → **폼형(267, 83%) 우선**.
2. **셀맵 추출이 곧 field 정의다.** `(label, cell, type)`이 그대로 `field_key`+주입위치+입력유형 → 262개 양식 필드를 손으로 정의할 필요 없음. ①이 ②의 field 정의를 흡수.
3. **정본 0.6 매트릭스 = process_forms의 source of truth.** `form→reg→process` 합성으로 매핑을 재생성하면 오배치가 자동 교정됨(0026이 그 구현).
4. **셀맵 휴리스틱**: 병합셀 중 텍스트 있는 것=라벨, 빈 것=입력칸. 입력칸의 **왼쪽 인접**(가로형) 또는 **위 인접**(세로형) 라벨과 짝. 직급/제목/체크박스(□) 라벨은 제외.

## 7. 기술 메모 (함정)

- **ExcelJS 라운드트립은 무손실 확인됨**(이미지·병합 보존). 단 파일 크기는 84%로 줄어듦(수식캐시·미사용스타일 정리, 정상).
- **PDF는 Excel COM**(`ExportAsFixedFormat(0, path)`)로. LibreOffice 불필요. COM은 try/finally로 `Quit()`+`ReleaseComObject` 필수(좀비 방지).
- **form_code → reg_code**는 접두어 환산이 100% 정확(검증됨): `B2100-01`→`B-2100`. 단 공식 비교는 `forms.reg_code` 명시값 사용 권장.
- **한글 CSV**는 UTF-8 BOM(`﻿`) 붙여야 Excel에서 안 깨짐.
- PowerShell node 실행 시 `[Console]::OutputEncoding=[System.Text.Encoding]::UTF8` 선행(한글 출력).

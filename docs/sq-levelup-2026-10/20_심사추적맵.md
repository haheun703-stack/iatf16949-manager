# 심사추적맵 — 관리계획서 중심 SQ 심사 동선 대비 (3+1 품번)

작성: 2026-07-17 · 근거: 각 품번 ISIR 풀세트(2권) 관리계획서 실물 판독 (`10_문서대장_*.md` §관리계획서)

## 0. 심사 동선과 이 문서의 사용법

SQ 심사원의 실제 동선은 4단계다. 이 문서는 각 단계에서 "심사원이 무엇을 소환하고, 무엇을 볼 것인가"를 관리계획서(CP) 공정별로 역산한 지도다.

1. **회의실 서류심사**: 선정 품번 ISIR → 관리계획서 정독 → CP에 적힌 관리방안(이력카드·C/SHEET·점검표·대장)을 하나씩 소환 → 기록 연속성·양식 필수항목 누락 확인
2. **현장검증**: CP를 들고 라인으로 → CP 조건·주기·설비가 현장 게시물/설정값과 일치하는지
3. **작업자 인터뷰**: "기준이 뭐냐, 어디 보고 아느냐, NG면 어떻게 하느냐"
4. **파생 확장**: 수입검사→1차사 보고, 외주관리(외주 ISIR 접수·협정·검수) 등 시스템 단위 확인

> **대원칙**: CP에 적힌 것은 전부 소환 대상이다. CP에 적어놓고 기록이 없으면 부적합, 현장에서 하고 있는데 CP에 없으면(예: 알곤 가접) 그것도 부적합이다. **문서=현장 완전 일치**가 목표.

## 3. 수입검사 → 1차사 보고 트랙

CP상 수입검사는 전 품번 공통 체계(5EA/LOT 이력카드 + 분기 M/SHEET + 반기 중금속). 심사원 확인 흐름:

1. **항목별 기록**: 품목별 이력카드에 외관/치수/재질 실측 기입 여부 (O표시만 있으면 지적)
2. **이상 발생 시 경로**: CP 비고란 "이상시 가공업체(또는 구매담당·표면처리업체) 통보·조치" — **통보 실적(부적합 통보서·회신) 존재 여부**
3. **1차사 보고·전달**: 정기검사 성적서(1권 세트)가 연 1회 1차사 제출물 — 제출 이력(접수증·메일)과 차기 제출 예정일 관리
4. **급소**: 밀시트 제3사 명의(세종에스피·엔디에프·대호특수강, R8) — "구매경로: 원소재 상사→가공외주→당사" 체인을 그림 1장으로 준비, 로트 연결(밀시트 Heat No ↔ 입고 LOT) 시연

## 5. 파생영역 ↔ CP 매핑 점검 (사장님 언급 영역별)

| 영역 | CP 근거 | 상태 | 조치 |
| --- | --- | --- | --- |
| 스폿 **팁 주기관리** | 28236: 연마 5,000/교체 20,000EA·카운터. 25460: 연마 50,000타 | CP에 있음 → **대장·카운터 실물 정합**이 관건 | K8 대장 최신화, 품번 간 기준 상이(5만 vs 5천) 사유 확인 |
| **알곤 가접 드레싱** | **4품번 CP 어디에도 없음** | 현장에서 실시 중이면 **CP=현장 불일치(중대)** | 실제 공정 여부 확인 → 있으면 CP 등재+토치/드레싱 주기 기준 신설, 없으면 용어 정리 |
| **원점(마스터) 관리** | LEAK OK/NG 마스터(시업전/1회/일), 벤딩 길이센서 MASTER | CP에 있음 | 마스터 시편 식별라벨·보관대·검출확인 기록(K7) 정비, NG 시연 리허설 |
| **금형·펀치** | 벤딩기(파워벤딩)·프레스는 외주(대철정공 등) | 사내=벤딩 금형, 프레스 금형은 외주 관리 | 사내 벤딩 금형 이력카드(타수·수리), 외주 금형은 업체 관리대장 확인 요청 |
| **스페어 파트** | CP 명시 없음 | 설비보전 영역 | 주요 설비(브레이징로·LEAK기·용접기) 스페어 리스트+재고 확인 |
| **설비 일상점검** | 시업전 1회/일(CP 명시) | K5 | 점검표 항목=설비 실물 일치 점검, 작업자가 "보면서" 하는지 훈련 |

## 6. 작업자 인터뷰 질문 은행 (리허설용)

**공통(전 작업자)**: ①이 공정에서 뭐가 제일 중요한 품질항목이에요? ②기준(조건)은 어디 보고 알아요? ③불량 나오면 어떻게 해요(격리→보고 경로)? ④자주검사는 언제, 몇 개, 어디를 봐요? ⑤MES 입력은 언제 해요? ⑥설비 점검은 아침에 뭘 봐요?

**공정 특화**:
- 스포트: 팁 몇 타에서 연마/교체? 카운터 어디? 연마 후 첫 제품은?
- 브레이징: 온도 몇 도? 이탈하면? 동링 누락은 어떻게 발견? 절단 용입은 언제 누가?
- LEAK: 마스터 언제 돌려요? NG마스터가 OK 뜨면? 압력·시간 설정 바꿀 수 있어요(권한)?
- 벤딩: 짧은/긴 마스터 왜 넣어요? 금형 교체 후 첫 검사는?
- 수입검사: LOT당 몇 개? 성적서 없으면 입고돼요? 불합격 통보는 누가?
- 포장: 이종혼입은 어떻게 막아요? 식별표 누가 붙여요?

**관리자(팀장)용**: ①특별특성이 뭐고 몇 개예요(◆/◈↔C 기호 대조 즉답)? ②CP 개정은 언제 뭐 때문에 했어요? ③공정능력은 어떻게 관리해요(28236 SPC 선언 답변 필수)? ④외주 ISIR·성적서는 어떻게 받아요?

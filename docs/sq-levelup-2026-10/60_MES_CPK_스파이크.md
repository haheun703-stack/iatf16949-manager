# 60. MES 데이터 기반 CP/CPK 스파이크 (2026-07-18)

**한 줄 결론**: MES 야간백업 덤프에서 **2026년 검사기록 42.3만 건·측정값 250만 행**을 꺼내
품번·검사항목별 **Cpk 1,344개를 실제 계산**했다. "CP/CPK 자료 부재"(심사 갭 #12, 윤대근 위원)는
이제 "자료 없음"이 아니라 "**MES에 다 있고, 계산기도 있다**"로 바뀐다.

## 1. 파이프라인 (재현 가능)

```
tspmes_YYYY-MM-DD.dmp (Oracle exp 야간백업)
  → scripts/mes_dump_extract.py     (덤프 판독, Oracle 불필요)
  → scripts/mes_cpk_spike.py        (규격+실측 조인 → CPK리포트 CSV)
```

- 산출물: `8. 자주검사...\TPC AM사업부 하위코드들 모음_260718\추출결과\CPK리포트_20260101이후.csv`
  (+ QMS_SQC/QMS_SQCDESC 2026년 전량 CSV, QMS_SPEC 규격 전량, MAC_DESC 설비일상점검 22.2만 행)
- 새 덤프를 받으면 같은 명령으로 그대로 재계산된다 (분기별 공정능력 평가 자동화의 씨앗).

## 2. MES 데이터 모델 판독 (다음 사람을 위한 기록)

| 테이블 | 의미 | 핵심 |
|---|---|---|
| QMS_SQC | 검사 헤더. **1행 = 검사항목 1개** | YMD+SEQ 키, QCGUBUN(W자주/I수입/P패트롤/O출하), POSITION=항목번호 |
| QMS_SQCDESC | 측정값 | YMD+SEQ로 헤더 조인, SUBSEQ=샘플 반복번호(항목 아님!), QCSTND=값 |
| QMS_SPEC | 검사규격 | PNO+QCGUBUN+POSITION 키. REMARK=항목명, **규격=NOMINAL±공차(SU=+측, SL=−측)**, SPCTYPE(NU=수치/OK=판정) |

⚠️ 함정 2개(실제로 밟았다): ①SQCDESC의 SUBSEQ를 항목번호로 조인하면 항목이 뒤섞인다 —
항목은 **헤더의 POSITION**이 정답. ②SU/SL은 절대 상·하한이 아니라 **공차**다
(REMARK "전류 7~9Ka" = NOM 8, SU 1, SL 1로 검증).

## 4. 진짜 발견 4가지 (심사 방어의 핵심)

### ① 단위혼용 109키 — 부적합 수치의 최대 원인 (데이터 등록 문제, 품질 문제 아님)
규격은 MPa(0.5~0.8)로 등록됐는데 현장은 kgf/㎠(5.79...)로 입력. 항목명에 이중 병기
("메인 압력 : 5~8Kgf/㎠ / 0.5~0.8MPa")된 리크/압력 항목 전반. 리포트에 kgf→MPa
환산(×0.0980665) '정규Cpk' 열 별도 제공. **조치: MES 규격 마스터 단위 통일.**

### ② 공정조건 항목은 Cpk 지표가 부적절 — 심사 답변 논리
압력·전류·온도 등 **조건관리 항목**은 라인/제품별 설정값이 정당하게 다르므로 산포가 크고
Cpk<1 이 정상이다. 공정능력 평가 대상은 **제품특성(치수 등) 항목**으로 한정해야 하며,
이는 CP의 관리방법 구분(L-4102 공정능력 운영지침)과 정합. → 심사 때 "조건 항목의 낮은
Cpk"를 지적받으면 이 논리로 방어하고, 특성 항목 리스트를 제시한다.

### ③ 제품특성(치수) 항목은 중심 정확, 산포 개선 대상
수입검사 외경 치수류: μ가 NOMINAL에 정확히 붙음(Φ14±0.3에 μ=14.03). Cpk 0.67~1.07 대역
— 공차 대비 산포(측정계 산포 포함)가 커서 1.33 미달. **개선 후보 목록이 데이터로 나온다.**
(best: 45270-4E010 Φ7.4±0.3 Cpk 40 — 사실상 전수 동일값 입력 의심도 병행 확인)

### ④ 실제 범위초과·기록습관 리스크
- 범위초과 후보: 38610-85800-R1 유량(규격 40~50, μ=54.5) · 28237-2MEA0-S1 전류(9.5~10.5,
  μ=11.3)·통전(2~3, μ=4.4) · 25451-07TC0-P3 R값(R2±0.3, μ=0.94 — 측정법/단위 확인 필요)
- **σ=0 키 43개**: 설정값을 그대로 입력(변동 0) — 심사에서 "기록 진실성" 지적 소지.
- 수치측정인데 규격 미등록: 144키 — QMS_SPEC 보완 대상.

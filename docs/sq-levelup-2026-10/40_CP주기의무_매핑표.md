# CP 주기의무 매핑표 — 관리계획서 기록물 → 앱 양식코드 → 관리자 TODO 전개

작성: 2026-07-17 · 원리: 관리계획서가 선언한 주기 기록 의무를 앱의 양식코드(하위코드)로 매핑하고,
**관리자 확인 의무**로 정기 의무(recurring_obligations)에 시드 → 홈 관제탑 팀별 보드에 자동 표출.
현장 기록(종이 C/SHEET·MES)은 현행 유지 — 앱 TODO는 "당일분 기입 확인"이라는 관리·감독 층이다.
완료 체크(obligation_completions)가 쌓이면 그것이 10월 심사의 **기록 연속성 증빙**이 된다.

적용: 마이그레이션 `0070_cp_gap_forms.sql`(갭양식 3종) + `0071_cp_cycle_obligations_seed.sql`(의무 시드).

## 5. 심사 트랙과의 관계

- **SQ 심사 트랙(0068/0069)** = 10월까지의 일회성 준비 프로젝트 (만료 인증서 교체, PSW 회수…)
- **CP 주기의무(0070/0071)** = 상시 운영 레일 — 7월부터 완료 체크가 쌓여 심사장에서 "석 달치 연속 이행"이 증빙
- 후속 연결 후보: 심사 트랙 3단계(현장검증) 항목이 해당 의무의 최근 4주 이행률을 각주로 표시

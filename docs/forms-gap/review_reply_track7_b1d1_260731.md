## 3. 추가 발견 1건 — L3100-02 마스터 결함은 이중이다 (기록 보강 지시)

헤더 자동조회 수식 실측: `=IF($I$2="","",VLOOKUP($I$2,`**`#REF!`**`,n,0))` — 조회키가 제목 병합에
갇힌 것에 더해 **VLOOKUP 참조 테이블 자체가 #REF! 로 소실**돼 있다(전 8칸 공통). 즉 시트를
교정하려면 ⓐ키 셀 위치 ⓑ참조 테이블 복원 **둘 다** 필요하다. "시트 교정 = 정본 관리 영역·앱 범위
밖" 판단에는 동의 — 다만 소견 ⑷ 기록에 #REF! 건을 병기해 두면 총무/품질보증 정본 교정 시 반쪽
수리를 막는다(규정 원문·H3100 코드중복과 같은 정본 정비 동선 편승 가능).

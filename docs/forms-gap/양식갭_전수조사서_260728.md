## 1. 실측 요약 — 갭의 실체는 3층이다

| 층 | 정의 | 실측 | 의미 |
| --- | --- | --- | --- |
| 전체 양식 | forms(비 deprecated) | **301종** | — |
| 작성 가능 | form_fields 정의 보유 | **167종** | 입력·저장 가능 |
| **갭A** | **셀맵(form_fields) 미정의** | **134종** | 작성 자체가 불가 — 본선 대상 |
| **갭B** | fields 有 · **엑셀 좌표(form_cell_map/grid) 無** | **5종** | 입력은 되나 엑셀 출력 매핑 없음 — 빠른 승리 |
| **갭C** | 원본(정본 파일) 실존 미확인 | 양식형 98 중 **실존 9 / 미발견 89** | 셀맵 정의 전 원본 확보 or 신규 설계 필요 |

**갭A 134의 세분(중요)**: **규정 본문형 36 + 양식형 98.**
규정 본문형(코드 `X-####`, 예: M-1200 공정관리 규정)은 0053 처리원칙("빠진 규정을 forms 로 등록해
목록 추가")의 산물로 **셀맵 대상이 아니다** — 이 36종 중 본문(regulation_sections) 보유 21, **미보유 15는
'규정 본문 적재' 트랙**으로 분리한다(양식 제작 아님). **실제 셀맵 제작 모수 = 양식형 98종.**

갭B 5종(전부 원본 실존·fields 완비 — 좌표만 붙이면 끝):
`K1200-07` 외주 ISIR·검사협정 접수대장 · `L2100-07` 수입검사 관리대장 · `L4102-02` 양산단계 공정능력 산출 ·
`M1200-10` 공정 자주검사 CHECK SHEET · `M1200-11` 브레이징 조건관리 CHECK SHEET

갭C 주의(판독 한계 명시): 실존 스캔은 4대 자료 폴더(전체 자료모음·갭양식 신규제작·팀별 구분 모음·서규하 SQ)
445파일에서 **파일명 코드 매칭** — 파일명에 코드가 없는 원본은 못 잡는 하한선이다. 그래도 89종 대부분은
목록표 기반 등록만 된 "빈 껍데기"로 판단(문서 BOM 파일없음 39와 같은 결). **경로 = 0065 갭양식 13종 선례:
원본이 없으면 수집을 기다리지 않고 표준 대장형으로 신규 설계(사장님·팀 검수로 확정)한다.**

참고 실측: 의무 연결 32종 · 프로세스 연결 283종 · SQ 연계 237종 / SQ 체크포인트 161 중 미비 116·부분 44 /

## 4. 원칙 (지시 반영 확인)

- **엑셀 출력 = 기존 셀맵→xlsx 파이프라인 재사용.** 신규 양식도 form_fields+form_cell_map 정의 =
  곧 엑셀 출력이 되게 하고 **별도 엔진을 만들지 않는다.** 갭B 5종이 이 원칙의 첫 검증대.
- 예시값 조작 차단(field_class)·작성자 auto(0097)·완료저장 게이트 등 기존 계약을 신규 양식에도 동일 적용.
- 진척 추적 = `forms-gap-audit.cjs` 재실행(갭A 건수 감소가 곧 진척률) — 완주 게이트 방식 그대로.

## 5. (종결) 질의 3건 — 7/28 밤 코워크 판정 (조사서 합격)

1. **배치 구성 = 승인.** 시퀀스 지정 1건 반영: **1배치 첫 반나절 = 갭B 5종 선두 필수** — 특히
   `L2100-07` 수입검사 관리대장은 스트림 B-3 트리거 소멸 감지("당일 수입검사 기록 감지")가 참조하는
   양식이라, 갭B가 먼저 끝나면 B-3 E2E 가 실양식으로 검증된다(A·B 맞물림 지점).
2. **원본 미발견 89종 = 신규 설계 우선 승인** (0065 선례). 조건 2개:
   ⑴ 신규 설계본에 **문서번호·개정번호·제정일 블록**을 IATF 문서관리 규정대로 박고, audit JSON 에
   **"신규 설계본" 표시**를 남겨 심사 때 대체 이력을 설명 가능하게 할 것.
   ⑵ 배치 검수 때 실물 대사 + 담당 팀 확인 1회 편승 — 확인에서 실물이 나타나면 **신규 설계본을 실물
   기준으로 교정**(버리는 게 아님).
3. **규정 본문 미보유 15종 = 별도 트랙 확인.** 원문 확보 = 사람 액션(사장님 액션 리스트 ③ — 김권표
   이사 자료 or 각 팀 보관본).

**전략 메모(코워크, 배치 반영 불요·인지용)**: 양식 제작은 "작성 가능"을 여는 것이고 SQ 증빙 충족은
작성 실적(현재 4/265)이 만든다 — **1~2배치 완료 시점에 "팀별 작성 운동" 착수를 사장님께 상신**할 것.
그 시점이 SQ 준비도 1%가 실제로 오르기 시작하는 지점이다.

## §2 실측 반전·발견 (기록)

1. **[반전] B2300 시트명이 한 자리 코드** — 시트 실존("B2300-1"~"B2300-7")하나 form 코드는 2자리
   (B2300-01~07)라 resolveSheet(name.includes) 매칭 불가. 마스터 무변경 원칙에 따라 **시트명 2자리
   정정 추출본** 경로 신설(엔진 무변경 — template_path 선례 내). 후속 배치 체크 항목: 시트명 코드
   자릿수 확인.
2. **[해소] L-4101-01 / L4101-01 이중 등록 의심(4배치 §2-⑤) 해소** — `L-4101-01 SPC 평가표`는 규정
   폴더의 **독립 .xls 파일**(구형 포맷), `L4101-01 Xbar-R 관리도`는 L-4101 지침 내장 시트로 **별개
   실체** 실측. 이중 등록 아님. SPC 평가표(.xls)는 엔진(ExcelJS) 판독 불가 포맷 — 처리(xlsx 변환 후
   정본 완결 여부)는 별도 판정 대상으로 보류.
3. **[발견] 마스터에 "정성품질 순회 점검 시트(B2300-3)" 코드 중복** — B2300-03 점검 체크시트와 같은
   코드를 단 **별개 양식**(순회 점검, forms 미등록). 등록 여부 + 코드 재부여는 판정 대상(§3-2).
4. **[반전] B2300-07 은 행 반복 대장이 아니라 병합 블록 1건 서술형** — 시트명("사례 시트")과 달리
   C6:F15 등 열 전체 병합 실측 → 문서형 5필드로 설계(대장 grid 오설계 회피).

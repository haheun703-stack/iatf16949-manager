# 게이트ⓑ 홈 개편 — 정보 손실 0 확인표 (17번 §3-4)

기존 홈(포털 1단계, 7/16~) 요소 → 새 템플릿 A 위치 매핑. **삭제된 정보·기능 = 0.**

| 기존 요소 | 새 위치 | 비고 |
| --- | --- | --- |
| 히어로(인사+내 할 일+완료/작성 액션) | 우측 레일 **[내 할 일]** 카드 | 완료·작성·확정 버튼 전부 보존(RailTasks). 이름 인사→카드 캡션 |
| 사용자 선택 유도(히어로 버튼) | 헤더 **사용자 칩**(클릭=전환 모달) + 레일 미선택 안내 | §4 첫 실행 모달 로직 무변 |
| 타팀 스트립(5팀 x/y·대표 연체·팀 상세 진입) | **도넛 범례**(팀별 done/denom, 클릭=팀 상세) + 매트릭스 팀 그룹 | 진입 기능 보존(onPickTeam) |
| MES 밴드(기준일·N일 지남 앰버·4종 누적 수치) | 헤더 **MES 칩**(N일 지남 앰버→클릭 시 MES 기록 현황) | 4종 누적 상세 수치는 mes-records 화면이 원 소유 — 칩에서 1클릭 |
| 경영지표: 오늘 이행률/남은/연체 | **KPI 타일**(완료율·연체) + 보드 카운터 | 남은 업무 = 완료율 타일 칩(x/y건)으로 병기 |
| 경영지표: 심사 D-day 타일 | 상단 **TopBar D-day 칩**(ⓐ에서 이동) | 중복 제거 — SQ 준비도 진입은 사이드바·심사탭 |
| 경영지표: 주간 완료 추이 | 도넛 카드 하단 **주간 스파크**(TrendBars 재사용) | |
| 경영지표: 팀별 오늘 이행률 바 | **도넛 범례**(팀별 x/y) | 팀별 허브 링크 = 사이드바 상시 |
| KPI 지수 스트립(35지표·대표/팀 필터·일괄 입력) | **그대로 유지**(그리드 아래) | 무변 |
| 오늘 할 일 보드(팀별⇄개인별·완료 처리) | **그대로 유지**(최하단) | 무변 — 매트릭스는 파악용, 보드는 액션용 |
| 미이행만 보기·정기 의무 관리 버튼(회사밴드) | **보드 헤더로 이동** | 기능 무변 |
| 팀 미배정 의무 정직 노출 | 그대로 유지 | 무변 |
| [데이터] 트리거 행(M3) | 매트릭스 **⚡ 행** + KPI '데이터 할 일' 타일 + 보드 유지 | 3중 표출·완료는 보드/레일에서만(✓ 사람) |

**신규(17번 §3)**: KPI 타일 5 · 이행 매트릭스(obligation:matrix, 조회 전용 — 팀별/개인별 탭) · 도넛.
**미구현 유보 1건**: 매트릭스 '주간' 탭 — 팀별/개인별 2탭으로 납품(주간 압축 뷰는 실사용 요구 시). 코워크 판단 요청.

## 질의 — document-bom 템플릿 재판정 (코워크 확인 요청)

현행 문서 BOM 은 이미 **좌 문서목록 + 우 상세 패널(ResizableSplit)** 구조입니다. 제2원칙(판정①,
"상세를 어디서 보느냐 — 같은 화면 우측이면 C")을 그대로 적용하면 item-tree·mes-trace 와 동일하게 **C**가 됩니다.
분류표는 B로 두고 있어 둘 중 하나를 선택해야 합니다:

- **(가) C로 재판정**(봇 권고) — 좌폭을 380px 규격으로 맞추고 미선택 요약만 추가. 구조 변경 없음, 판정① 일관.
- (나) B 유지 — 우측 상세를 걷어내고 행 클릭 시 별도 화면으로 보내야 하며, 현행 대비 동선이 길어집니다.

회신 전까지 document-bom 은 손대지 않았습니다(헤더·토큰 정비도 보류). **A 9 · B 4 · C 15** 집계는 재판정 시
**B 3 · C 16** 으로 바뀝니다.

## 4. 갭3 — 연결고리(uses vs owns) 모델 부재

- **앱 모델**: `process_forms` = 양식의 소유 프로세스 1곳 (0.6 부서매트릭스 기준, 0026 교정). 219행.

- → **"프로세스 사용 양식(단계·순서 포함)" = many-to-many 차원이 앱에 없음.** 이게 사용자가 말한 "연결고리"의 정체. 추가하면 "생산관리는 이 양식들을 이 순서로 쓴다"를 보여줄 수 있음.

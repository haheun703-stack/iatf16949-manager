# 관련 양식(process_forms) 정합성 검증 리포트

**작성 2026-06-30** · 기준=프로세스 흐름도(캡쳐본 적용 본문)가 참조하는 규정 vs 현재 매핑.

## 결론

현재 매핑은 흐름도 기준과 **부분적으로 어긋남**. 단 자동 일괄수정은 비권장:
- **추가(흐름도O·매핑X)**: 흐름도는 *규정* 단위를 참조 → 그 규정 양식 전부 링크 시 과링크 위험(예: 영업이 개발규정 참조 ≠ 개발양식 14개 전부).
- **제거(매핑O·흐름도X)**: 흐름도는 *주 흐름*만 도식 → 프로세스 소유 양식이 미표기될 수 있어(예: 경영관리의 표준관리·윤리경영) 자동 제거 위험.
- **횡단규정** B-2100(시정조치)·A-2200(회의록)·L-2100(검사)는 다수 프로세스 공통 → 일괄 추가 시 노이즈.

→ **권장: 본 리포트를 근거로 프로세스별 명백한 항목만 선별 정리.**

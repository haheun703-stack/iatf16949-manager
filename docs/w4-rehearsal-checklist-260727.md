# M1 태블릿 준비 — 현장 설치 0 (참고 문서)

**태블릿에 설치할 프로그램 없음.** 준비 = ①크롬 열기 ②주소 입력(`http://qms:8080` — (b)단계 후) ③입고 담당자 계정 로그인 ④홈 화면에 바로가기 추가. 이후 현장 동작 3개: **크롬 열기 → [입고 사진 찍기] → 찍기**. 화면 수정은 서버 갱신+새로고침만 — 태블릿을 다시 만질 일 없음(웹 전환의 존재 이유).
현장 화면은 원버튼 사진함(15번 §0.5-2): 입력 0개, 자동 기록 3개(시각·세션 사용자·'입고' 태그). 구조화(거래처·품번·업체LOT)는 사무실 태깅 화면에서 하루 1회 — 태깅 전 사진도 '미분류 입고 증거'로 유효.

## §4 제안 범위 (v1 — 표시 전용 · 쓰기 0)

1. **진입**: 32호 §1 타이틀 줄 우측 유틸 **"TV현황판"** → 전체화면 전광판 모드(§1 원문 "별도 전광판
   모드로 분리"). ESC/닫기로 복귀. 5층 골격 예외 화면(툴바·조회조건 없음 — 표시 전용).
2. **본체**: 미완료(진행·계획) 작업지시별 도넛 — 달성률 = 실적÷지시(100% 초과 그대로 · 지시 0/null =
   '—'), 내부 지시·생산·불량(수집 '—'), 하단 품번·품명. 착색 = 달성률 구간(진행 중 = 주황 계열 ·
   100% 도달 = 녹색 계열 — 색+숫자 병기, CVD 문법 유지).
3. **상단**: 오늘 일자 + 조업시간(달력 실측) + 마지막 갱신 시각.
4. **갱신**: 60초 폴링(판정 ②) — 조회 채널 재사용 원칙, 필요 시 조회 1종만 신설(쓰기 0).
5. **돈 경계**: 수량·%만 — 금액·단가 0(헌법 15번).
6. **계측 겸용**: perfWatch(0141) 마크 동반 — 장시간 방치 화면 = longtask·하트비트 관측 최적 지점
   (멎음 트랙 부수 효과).

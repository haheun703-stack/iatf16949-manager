## 5. 반영 — **재기동 없음 · 재로그인 불필요**

오늘 변경은 **렌더러 한정**이라(server·main·마이그 0건) 라이브 서버 프로세스를 건드릴 이유가
없다. 서버는 `express.static` + 매 요청 `index.html` 디스크 재판독 구조라 **새 번들이 즉시
서빙**된다(자산 `index-CBIs5mud.js` HTTP 200 실측).

> **직원분들 조치 = 브라우저 새로고침 1회.** 세션 유지 — 근무 중 강제 로그아웃 없음.

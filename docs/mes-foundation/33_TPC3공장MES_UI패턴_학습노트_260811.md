## §2 확정 문법 (오전 7장 + 전수판독 종합)

1. **화면 4형 체계**: ① 모듈 홈(대시보드형 = KPI 카드+차트 / 메뉴형 = 서브메뉴+아이콘만) ② 관리 = 필터바+CRUD 그리드 ③ 현황 = 조회 그리드+인쇄·엑셀 ④ **문서형 리포트 = 로고·제목·결재란 포함, 인쇄 전제**. 32호 §1-5(카드류 조회 화면 금지)와 정합.
2. **모듈 홈 이원화**: 지표가 실시간으로 쌓이는 모듈(구매·생산·영업·부적합)만 대시보드, 나머지는 메뉴형 — 전 모듈 KPI 강제가 아니다. 데일리Q도 데이터 있는 모듈부터 대시보드.
3. **성과 지표 표준형**: 연간 콤보차트(막대+선) + 하단 월별 표 + [월간으로전환]. 지표 5분류(경영·영업·생산·관리·품질).
4. **그리드 색상 코딩**: 번호=빨강, 품명=파랑 링크(+품번 첨자), 금액=주황, 수량=파랑, 필수 입력=노랑 배경.
5. **추적 화면 문법**: 공정 흐름 밴드(수량 열산) → 공정별 LOT 그리드 → 원소재 → 납품 — 위에서 아래로 "지시→공정→출하" 서사.

## §3 채택하지 않는 것

데스크톱 고정폭·광고 배너·고객센터 카드·구식 팝업 폼(그림13 UX는 흡수하되 팝업 창 방식은 페이지/모달로)·디자인 원색 복제(상용 제품 — 골격만 참고, 색은 우리 파스텔 토큰 + 32호 §7-① 진한 단계).

## §4 SQ·IATF 직결 발견 (심사대응 설계 참고)

- **품질 모듈 메뉴명 = SQ 심사 항목의 실체**: 자주/순회 검사·수입검사(공정제품/원소재)·출하검사·특별특성 X-R관리도·정기검사·한도견본·신뢰성·승인문서·검교정·게이지R&R·4M 변경 — 심사대응 매핑 테이블의 SQ 항목 축과 1:1 대조 가능.
- **작업표준서 시스템 출력**(그림14) — 자주검사 표준 내장 + 개정이력 + 서식번호. 우리 문서BOM 165종 출력 자산과 동형 — "심사 문서는 평소 기록의 부산물" 실증 사례.
- **수입검사부적합 PPM 지표**(그림25)·**부적합 PPM 대시보드**(그림12) — SQ 성과지표 요구 그대로.
- **화면별 권한 7종 매트릭스**(그림33) — 판매형 필수(특히 **단가 보기 권한 분리**). 데일리Q 라이선스 플래그(IATF 애드온)와 같은 축으로 설계 가능.
- **조업달력**(그림31) — 가동률·계획대비 분모. 데일리Q에 아직 없는 개념 — 2차분 후보.

## §5 상품 구조 방향 (사장님 8/11 + 봇 동의)

- 기본판 = 미니MES(무른모 타입 골격) + SQ 심사 항목 내장. IATF16949 = +@ 판매 애드온 — 심사대응(SQ/IATF) 메뉴 안 라이선스 플래그 1개로 IATF 뷰·문서BOM·조항 열 잠금/언락. 별도 앱·DB 아님.
- 불변 조건: 기록→요구항목 매핑 테이블은 처음부터 {SQ 항목번호, IATF 조항} 2열 겸용.

## §6 32호 1차분 6화면 영향 판정

- **골격 변화 없음** — 5층 골격·화면 3형(+문서형 리포트) 그대로. 1차분(MES 홈·작업지시관리·생산실적·수입검사내역·자주/품질검사내역·재고현황) **착수 가능**.
- 1차분 반영 추가분: ① 모듈 홈 대시보드 층(데이터 있는 모듈부터) ② 그리드 색상 코딩·필수 입력 노랑 문법 ③ 검사내역 화면에 "검사내역 보기" 링크 문법(그림27).
- **2차분 후보 등재(재상신용)**: 부적합 PPM 대시보드(그림12)·성과 지표 표준형(그림19~25)·추적 공정 흐름 밴드(그림26·27)·화면별 권한 매트릭스(그림33)·조업달력(그림31)·문서형 리포트(그림17·18).

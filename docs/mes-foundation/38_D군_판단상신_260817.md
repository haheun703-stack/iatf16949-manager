## 1. ★M-9 — 즉시 착수분 **완료** (도장 대기 = 라이브 재기동 1회)

**결함**: 핸들러가 `createdBy` 의 **존재 여부**를 "완료 저장" 신호로 쓰는데, 디스패처 STAMP 가
세션 이름을 **무조건** 채워 넣어 초안·자동저장까지 완료 저장으로 오인 → fact 공란 검사에 걸려 500.
그 예외를 `FormCanvas` 자동저장 `catch` 가 삼켜 **양식 이동 시 작성 중 내용이 말없이 소실**.

**처분 2건**

1. **서버** — `STAMP_ONLY_IF_PRESENT`(양식 저장 2채널 한정): **값을 보냈을 때만** 세션 이름으로 덮어씀.
   - 위조 방어 **불변** — 값을 보내면 언제나 세션 이름으로 덮어씁니다. 클라가 쥔 것은 "값"이 아니라
     "완료 의도(필드 유무)"뿐이고, 그건 종전에도 클라의 몫이었습니다.
   - 폴백 금지 **불변** — 서버가 주체를 지어내지 않습니다(없으면 없는 채로 초안).
   - 나머지 채널은 종전대로 무조건 주입(유무가 의미를 갖지 않고, 빠지면 `REQUIRED_FIELDS` 가 400).
2. **렌더러** — 자동저장 실패 시 **이동을 취소**하고 사유를 표시(`autoSaveOrWarn`).
   종전 주석은 "데이터 손실 방지"였으나 실제로는 **값을 버리는 경로**였습니다. 저장에 실패했으면
   화면을 떠나지 않는 것이 보존입니다.

**실증 — 전후 대조**(`scripts/e2e-m9-draft.mjs` 신설)

| 단계 | 수정 전(:8081 구판) | 수정 후(임시 :8102) |
|---|---|---|
| 1 초안 저장(createdBy 미전달) | **500** `'측정값(너트 스폿)' 칸이 비어 있습니다` | **200** · `created_by` 공란 |
| 2 완료 저장 + fact 공란 | 거부 | **거부 유지**(서버 최종 관문 생존) |
| 3 완료 저장 + `createdBy:'위조'` | 200 · `created_by=E2E봇` | **동일**(STAMP 불변) |
| 4 초안 이어쓰기 | **500** | **200** · 완료로 승격되지 않음 |
| 합계 | **4/8** | **8/8** |

표본 = `M4200-01`(fact 106칸) — 8/13 검수 실측과 동일 표본입니다.
회귀 **153/153** · typecheck · build · build:server.

> **▶ 도장 필요 1건 — 라이브 재기동**: M-9 는 **서버 변경**이라 재기동해야 반영됩니다.
> 렌더러분(이동 취소·경고)은 빌드로 이미 반영돼 있어, 재기동 전에도 **소실은 멈추고 경고가 뜹니다**
> (저장 실패 시 이동을 막으므로). 재기동하면 초안 저장 자체가 정상화됩니다.
> 일요일 저녁이 창으로는 가장 쌉니다(재로그인 1회).

## 2. 판단 요청 — M-8 로그아웃 죽은 라우트

**결함(실증)**: Express 가 `:login` 을 **경로 파라미터**로 파싱해 `/api/auth*` 전부를 로그인 핸들러가
삼킵니다. `POST /api/auth:logout` → `400 {"error":"이름을 입력하세요."}`.
→ **공용 PC 에서 세션을 끊을 방법이 4시간 유휴 대기뿐**이고, 사용자가 자기 비번도 못 바꿉니다.

**처방 후보**

| 안 | 내용 | 대가 |
|---|---|---|
| **안1(권고)** | 경로를 `/api/auth/logout`·`/api/auth/changePassword` 로 변경(슬래시 구분) | 폴리필·렌더러 호출부 동반 수정 · **경로 계약 변경** |
| 안2 | 라우트 등록 순서를 바꿔 정확 일치 라우트를 먼저 | Express 파라미터 파싱 자체는 그대로 — 취약 |
| 안3 | 로그아웃을 채널(`POST /api/{channel}`)로 흡수 | 인증 경로가 디스패처에 섞임(경계 흐림) |

**동반 필수**: 고치면 `changePassword` 의 **현재 비번 미확인**(잠복)도 같이 닫아야 합니다 —
지금은 세션만 있으면 남의 자리에서 비번을 바꿀 수 있습니다.

**판정 요청**: 안1로 진행할까요? (경로 계약 변경이라 도장 요청)

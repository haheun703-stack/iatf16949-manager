## 2. 채널 — `semimes:tvBoard` (읽기 전용 · 신설 1종)

- 미완료(대기·진행) 지시 + 연결 실적 합(okSum·ngSum — **취소 제외**) + 오늘 조업달력 행 +
  전체 건수(total). limit 클램프 1~60(기본 24) · 달성률은 화면 계산(서버는 원자료만).
- 마이그 0 · 쓰기 0 · REQUIRED_FIELDS 해당 없음(전 필드 선택).

# 화면 문법 노트 4차 — 증권 HTS 판독 (2026-08-04)

> **원천**: 루트 `새로본 증권 프로그램\` 캡쳐 16장(사장님 제공, 8/1 촬영). 사장님 지목 3가지 =
> 색 문법·직관 조작 타입·엑셀형 기록 공간. ⚠색 방향의 **최종 확정은 §1**(빨강=적자·파랑=흑자,
> 8/4 2차 지시로 최초 발언을 스스로 반전) — 헤더가 아니라 §1을 따를 것.
> 성격 = 판독 + 이식 후보. **채택 = 29번 §11·PB2 견적 추기.**

## §1 색 문법 (16장 일관)

- **배경 = 전부 화이트(라이트).** 다크 0장 — 30번 v2 파스텔 방향과 충돌 없음.
- **빨강 = 상승/플러스 · 파랑 = 하락/마이너스** — 매수/매도가 아니라 **순수 증감 부호 축**.
  2단 적용: ①숫자 텍스트 착색 ②셀·행 배경 **파스텔 히트맵**(분홍/하늘, 농도 = 크기).
- 노랑 = 형광펜이 아니라 **★즐겨찾기 별**과 팔레트 스와치에만. 검정 = 툴팁 배경·기본 텍스트.
  베이지/회색 = 구분 경계(날짜열·주간 경계).

### 색 축 확정 (8/4 사장님 최종 결정 — 증권 문법 반전)

증권은 빨강=상승이지만, **사장님 확정: "대부분 사장/회장은 빨강=적자·파랑=흑자로 읽는다"** →
- **부호 축**(수치 증감·계획대비 차이): **빨강 = −/부족·적자 · 파랑 = +/초과·흑자**
  — ★TPC MES 기존 화면(계획대비실적·안전재고: 빨강=미달/파랑=초과)과 **정확히 일치, 충돌 소멸.**
  판매 시 고객 요구가 갈리면 반전 옵션(설정 1키)으로 대응 — 기본값은 본 확정.
- **판정 축**(정상/경고/위험): 기존 신호등(초록/호박/장미) + 기호(●◐×) — 30번 v2 그대로
- 부호와 판정을 같은 색으로 섞지 않는다(미달 "경고"는 호박, 부족 "수치"는 빨강).

## §2 직관 조작 문법

프리셋 버튼 줄(1클릭 = 지표 세트 통째 교체, ★노란 별 즐겨찾기) · 세그먼트 토글(정규화/절대값)
· 기간 칩(1W~15Y·연도·월 — 날짜 타이핑 제거) · 범례 체크박스 계열 on/off · **"색상 ON/OFF"
단일 토글**(히트맵 전체 껐다 켬 — 인쇄용/모니터용 전환) · 탭에 닫기(×)·추가(+) = 조회 세트 저장
· 좌우 2분할 그리드 · 히스토리/관심종목 패널 · 크로스헤어 + 검은 반투명 툴팁(계열색 칩).

## §3 엑셀형 기록 공간

자유 메모장은 없고, **하단 고정 대형 그리드**(병합 헤더·열그룹 배경·고정 헤더)가 엑셀 역할 +
**엑셀 다운로드·화면 캡쳐·요약 복사** 버튼으로 기록을 밖으로 뺀다. → 사장님 요구("엑셀처럼
적고 저장")는 여기에 **인그리드 편집**(TPC MES 관리자 그리드 문법 — 셀 콤보·체크 + 저장 버튼,
3차 노트 §2)을 결합하면 완성: **보는 표(HTS) + 적는 표(MES 그리드) + 내보내기(HTS) 3합.**

## §4 데일리Q 이식 채택 후보 (PB2 반영)

1. 부호 착색 2단(숫자+파스텔 히트맵): 품번×공정 수불·계획대비 열에 적용 — **빨강=−/파랑=+ (§1 확정)**
2. "색상 ON/OFF" 토글 1개 — 심사 뷰·매트릭스 공용
3. 상단 프리셋 버튼 줄 = 뷰 전환(공정실황·수불·불량·설비·심사항목) 원클릭
4. 기간 칩(일/주/월/분기·연도) 고정 배치
5. ★노란 별 = 중점관리 품번·항목(관심종목 이식) + 히스토리(최근 본 품번)
6. 하단 엑셀형 그리드: 병합 헤더(공정 그룹×계획/실적/차이) + **인그리드 편집·저장** + 엑셀 다운로드·캡쳐 버튼
7. 탭 닫기·추가 = 조회 세트 저장(여러 날짜·라인 병렬 비교)
8. 크로스헤어 툴팁(추이 차트 도입 시)

# 지시서 32호 — MES 정본 재편 (방향 정정)

- **발행일**: 2026-08-06
- **발행 근거**: 사장님 방향 정정 지시(8/6) — "TPC MES 화면 캡쳐를 참조해서 **프로그램을 MES로 바꾸고**, 그 안에 SQ 항목을 넣어 심사받을 수 있는 프로그램으로 변경하라. 지금은 되어 있는 것에 어거지로 끼워 넣는 걸로 보인다."
- **효력**: 본 지시서는 29~31호의 **화면 방향 해석을 대체**한다. "겉이 MES, 속이 SQ"의 유권 해석 = **프로그램 골격 자체가 MES**이고 SQ가 그 안에 스며드는 것. 기존 앱(관제탑 중심)에 MES 요소를 얹는 방향은 폐기.
- **정본**: `TPC MES 화면 캡쳐/` 폴더의 캡쳐 65장 + 엑셀 내보내기 9종. 30번 목업은 참고자료로 격하.

---

## §0 어긋남의 기록 (재발 방지용)

- 3차 노트(캡쳐 전수 판독)가 있었음에도, 캡쳐를 **화면의 정본**이 아니라 메뉴 이름·배지의 소스로만 사용 → 기존 SQ 앱 골격(관제탑 첫 화면·카드 UI) 위에 MES 요소를 부착하는 방향으로 진행됨.
- 코워크·봇 공동 책임으로 기록. 이후 화면 작업은 §4 대조표 도장 없이 착수 금지.

## §1 MES 화면 문법 (캡쳐 실측 — 그림23 작업지시관리 · 그림30 수입검사내역조회 기준)

모든 화면이 다음 5층 골격을 따른다:

1. **타이틀 줄**: `데일리Q - {화면명}` + 우측 유틸(홈 / 공정별 모니터링 / TV현황판 / 사용자 / 로그아웃).
2. **1차 메뉴(남색 메가바)**: 기준정보관리 · 자재관리 · 생산관리 · 품질관리 · 설비관리 · 금형관리 · 경영정보 · **심사대응(SQ/IATF)** · 관리자 · 즐겨찾기 — 캡쳐의 남색 바 문법 그대로. (영업·개발은 헌법상 제외 — 15번 경계 유지.)
3. **2차 메뉴 탭 줄**: 1차 선택 시 하위 화면들이 가로 탭으로 나열, 현재 화면 하이라이트(캡쳐의 "작업지시관리" 강조 방식).
4. **8버튼 툴바(전 화면 고정)**: 초기화 · 조회 · 추가 · 저장 · 삭제 · 엑셀 · 인쇄 · 닫기 (+우측 즐겨찾기 등록). 미지원 버튼은 흐림(이미 확립된 정직 문법). 위치·순서·아이콘 전 화면 동일.
5. **조회조건 바 + 엑셀형 그리드 본체**: 일자 범위·품번·콤보 조건 바, 아래는 화면 전체를 쓰는 그리드(번호 열·필터 화살표 헤더·행 선택). 카드·도넛·배너류는 조회 화면에 두지 않는다.

- **전광판(TV현황판)**: 그림65(생산현황 도넛 보드)는 별도 전광판 모드로 분리 — 우측 상단 유틸에서 진입. PB2의 도넛 7카드는 홈에서 빼서 이 모드에 흡수.

## §2 첫 화면 교체 (주객 복구)

- 로그인 직후 = **MES 홈**: 남색 메뉴바 + 즐겨찾기/최근 화면 + 오늘 요약 한 줄. 캡쳐의 관리자 프로그램 첫인상 그대로.
- 기존 관제탑(문제 배너·TOP5·심사 D-70)은 **심사대응 메뉴의 첫 화면**으로 이동 — 삭제 아님, 자리 이동. 문제 배너 1줄만 MES 홈 상단에 남긴다(31호 §2-1층 유지 — 눈에 보이는 관리).

## §3 SQ 통합 방식 ("속이 SQ" — 화면을 바꾸지 말고 화면 안에 심는다)

1. 그리드 화면의 열로: 검사 계열 화면에 근거양식 코드·SQ 항목 배지 열(기존 배지 재사용).
2. 기록 화면의 계약으로: 초중종·REVISION 스냅샷·확인자 2단·STAMP — PC-1 서버 계약 무변경 이식.
3. 심사 뷰·SQ 대시보드: 심사대응 메뉴 하위로 전부 수용(PB2-ⓒ 재사용).
4. 데이터 할 일 트리거(T1~T4): 무변경 — 보드는 심사대응 메뉴에서.

## §4 착수 관문 — 화면 대조표 도장 (이번 어긋남의 재발 방지 장치)

배치 착수 **전에** 봇은 다음 대조표를 상신하고 사장님 도장을 받는다:

| 열 | 내용 |
| --- | --- |
| 캡쳐 | 파일명(예: 생산관리/그림23.png) |
| 화면명 | 작업지시관리 등 (3차 노트 트리 기준) |
| 재현 범위 | 전면 재현 / 골격만 / 제외(사유) |
| SQ 심기 | 이 화면에 들어갈 SQ 요소 |
| 원천 | 기존 화면 재사용 / 신규 |
| 순번 | 1차분 / 2차분 / 후순위 |

- **1차분 권고(코워크)**: MES 홈 · 작업지시관리(그림23) · 생산실적(그림24~26 계열) · 수입검사내역조회(그림30) · 자주/품질검사내역(그림33~36 계열) · 재고현황(자재) — "팀별 매일 입력 1~4화면"(3차 노트 발견)과 일치하는 최소 세트.
- 대조표 없이 화면 커밋 금지. 대조표 도장 후에는 배치별 기존 규율(첫 줄 하네스·복사본 선반영·코워크 캡쳐 대조 검수) 그대로.

| 자산 | 처분 |
| --- | --- |
| 서버 계층 전부(채널 165·계약·수집함·트리거·마이그 0101~0137) | **무변경 재사용** |
| KPI 실적 그리드(ⓔ-2) | 존치 — 이미 MES 그리드 문법. 경영정보 2차 메뉴로 |
| SQ 심사 뷰(ⓒ) | 존치 — 심사대응 메뉴로 이동 |

| 관제탑·TOP5 보드 | 심사대응 첫 화면으로 이동 |

## §6 검수 방식

- 코워크가 화면마다 **좌: MES 캡쳐 / 우: 구현 화면** 나란히 캡쳐 대조로 판정. 골격 5층(§1) 일치 여부가 합격 기준.

## §7 판정 확정 (사장님, 8/6)

1. **테마 색 = ⓑ 확정**: 골격은 MES 5층, 색은 **밝은 파스텔 유지**. 단 **강조·대제목은 진한 파스텔톤** — 1차 메뉴바·화면 타이틀·툴바 활성 버튼에 진한 톤 적용(기존 파스텔 토큰에 진한 단계 추가). 코워크 ⓐ 권고는 기각 — 사장님 결정이 정본.
2. **1차분 6화면 승인**: MES 홈 · 작업지시관리(그림23) · 생산실적(그림24~26) · 수입검사내역조회(그림30) · 자주/품질검사내역(그림33~36) · 재고현황(자재).
3. **전광판 모드 = 후순위 확정** (코워크 추론 위임분): 근거 — ⑴ 1차분 6화면이 팀별 매일 입력 동선(3차 노트 "1~4화면") 전부를 커버하고 전광판은 표시 전용이라 기록 축적·심사 준비에 기여 0 ⑵ 전광판은 현장 설치(모니터·거치) 시점과 맞물리므로 PC-2 스캔 UX와 함께 현장 배치 배치에서 다루는 게 효율. 1차분 검수 통과 시 2차분 후보 1순위로 재상신 → 사장님 재배치.

## 1. 쉬운 설명
기본 메뉴는 다 열려 있고, **IATF 메뉴 4개**(IATF 대시보드·조항 커버리지·문서 BOM·프로세스 작업장)에만 자물쇠. 최종관리자가 **열쇠(라이선스 키)**를 넣으면 열림. 열쇠는 **회사명에 묶여** 발급(다른 회사 열쇠는 안 열림).

## 4. 코워크 확인 요청(:8083 pid 19472)
1. E2E봇(manager)으로 심사대응 → IATF 대시보드 클릭 → 🔒 패널 + "관리자에게 문의"(manager 라 키 입력 불가) 육안.
2. **판단 요청 ①** 잠금 4화면이 맞는지(33호 §60 기준 + 프로세스 작업장). 내부심사 양식 4종·규정 뼈대 열람은 **양식/문서 안에 섞여 있어 화면 단위로 못 잠금** — 애드온 경계 = "화면 4종"으로 갈지, 양식 코드(A5100·A5200)까지 갈지.
3. **판단 요청 ②** 키 v1(회사명 HMAC·오프라인) — 코드에 salt 가 있어 복제 가능. 판매 전 M4에서 서명 키/온라인 검증으로 올릴지. 시연·파일럿엔 충분.
4. **★라이브 반영 도장 요청** — 라우트 버그는 라이브 사용자에게도 해당(로그아웃 무효·비번 변경 불가). M2 서버 코드 세트(마법사·스위치·라이선스·라우트)로 재기동 1회. 라이브엔 users>0·플래그 없음이라 마법사/복사본 변경은 무영향.

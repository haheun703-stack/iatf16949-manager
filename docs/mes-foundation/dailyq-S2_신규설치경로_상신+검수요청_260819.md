## 4. 발견·후속 (M2 로 넘김)

- **`health.copy` 의미 충돌**: 서버는 "IATF_DATA_DIR 지정 + 라이브 경로 아님"을 검수 복사본으로 판정 → 고객사 설치(자기 경로 지정)가 **"검수 복사본 — 실기록 입력 금지" 표지**를 달게 된다. M2 설치 마법사에서 명시 플래그(`IATF_REVIEW_COPY=1`)로 분리 필요 — 하네스 게이트(`assertCopyServer`)와 함께 코워크 협의.
- 자동기동 = 직전 도장 빌드 고정(41호 확정) — M2 설치판 창에서 처리.

## 신규 경미 소견 1건 (차기 편승)

- **401(세션 만료)이 "조회 실패 — 통신 오류"로 뭉뚱그려 표기**되고 로그인 유도가 없음. 재기동 직후 스테일 세션에서 실측(생산실적 등록·specList·partnerList 전부 401 → 화면은 통신 오류). Major ①의 catch 자체는 작동(빈 그리드 오안내 없음 — 그 부분은 합격)이나, 401 분기만 "세션이 만료되었습니다 — 다시 로그인하세요" + 로그인 리다이렉트로 구분 요망. W4 세션 영속화 소견과 같은 축.

# 32호 §4 — 화면 대조표 상신 (2026-08-06, 사무실 봇 · 도장 관문)

> **도장 기록(8/6 저녁)**: 사장님 "니가 직접 진행하고 코워크한테 기대지 말고 진행해" —
> 본 지시를 §4 도장으로 갈음(코워크 사전 검토 생략, 사후 검수로 전환). 이에 따라
> **1차분 0번 골격(5층 프레임·남색 메가바·2차 탭·심사대응 메뉴·MES 홈) 당일 착수·반영.**
> 코워크 대조 검토는 배치 검수(§6 좌우 대조)에서 사후 수행.

> **근거**: 32호 §4(착수 관문 — 대조표 도장 없이 화면 커밋 금지) + §7 판정 3건(파스텔+진한
> 강조·1차분 6화면·전광판 후순위). **화면명 = 캡쳐 65장 전량 실물 판독**(병렬 판독 8/6 —
> 추정 기입 금지, 판독 불확실분만 "(추정)" 표기). 폼ID = 캡쳐 타이틀바 실측.
>
> **재현 범위 3분류**: 전면 재현(그리드·기능까지) / 골격만(5층 프레임 + 조회, 편집은 후속) /
> 제외(사유 명기 — 헌법 "돈 계열 금지"·원천 부재). **제외해도 캡쳐·트리 기록은 보존**(§5).
>
> **순번**: 1차분 = §7-2 도장 6화면 · 2차분 = 매일 입력·심사 연결 잔여 · 후순위 = 표시 전용·
> 원천 부재·현장 설치 종속. **0번(골격)** = 5층 프레임·남색 메가바·2차 탭·8버튼 툴바 공통
> 컴포넌트 + MES 홈 — 모든 화면의 전제라 1차분 첫 배치에 포함.

## 1. `scripts/lib/e2e.mjs` 신설 — 3중 게이트 공용화 (Critical ② 종결)

  + `assertBaseNotLive` — `E2E_BASE` 가 :8080 이면 fetch 한 발도 나가기 전에 거부.
- **③ `guardLoginName`** — argv 로그인 계정은 **'E2E봇'만**(빈 값 = E2E봇 기본). 실무자

  명시 API(규칙 자체 정리 규약 주석)로만.

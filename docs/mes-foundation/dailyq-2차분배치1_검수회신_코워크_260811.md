- **ConfirmDialog 실전 작동** — SPEC 등록·개정 확인창이 커스텀 창으로 표출. 네이티브 confirm이었다면 원격 조작이 차단됐을 것 — 어제 묶음 배치의 가치가 하루 만에 실전 증명.

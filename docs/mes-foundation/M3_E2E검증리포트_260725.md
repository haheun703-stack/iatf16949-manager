## 구현 요약
- `src/main/ipc/trigger-engine.ts` — 평가(멱등)·발행·해소표시·취소·배정 4규칙. 평가 시점 = 관제탑 보드 조회 시(lazy·결정론, 별도 엔진/스케줄러 없음 = §1-3).
- 내장 트리거 2종(코워크 7/25 승인, trigger_kind='audit_gap'):
  - **T1 심사 갭**(entity_kind='obligation') — 의무 연체 ≥7일(config `overdueDays`) → 의무별 1건. 팀 = 기존 의무와 동일 규칙(양식 resp_dept→owner 정규화).
  - **T2 증거 공백**(entity_kind='mes-feed') — 사이드카(mes_records.db) 최신 데이터일 < 어제 → 공백 구간당 1건(버킷=공백 시작일, 일별 스팸 방지). 팀 = 생산팀.
- 보드 합류 = TEAM_TODAY_BOARD 확장(`[데이터]` 배지·`해소됨` 칩). "오늘 할 일" 정본 = 관제탑 하나.
- 완료 = `obligation:triggerComplete`(✓는 사람만·완료 건 불변). 서버 REQUIRED_FIELDS 등록(웹 시 doneBy 세션 강제).

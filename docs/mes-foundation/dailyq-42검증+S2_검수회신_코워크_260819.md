## D. ★코워크 소견 — health.copy → IATF_REVIEW_COPY 분리 시 fail-closed 유지 (S2 §4 협의)

봇 제안(명시 플래그 분리)에 **동의하되 조건 1개**: 검수 복사본 판정을 `IATF_REVIEW_COPY=1` **명시 플래그**로 바꿀 때, 그 플래그가 동시에 **①빨간 표지 ②E2E봇 로그인 허용(lib/e2e.mjs guardLoginName)**을 여는 유일 스위치가 되어야 합니다. 그래야 **고객사 설치(플래그 없음) = 표지 없음 + E2E봇 불가 + 실기록**으로 fail-closed 됩니다.

# 현장 화면 문법 노트 — TPC MES 화면설계서(★6 SF-TD3, 2025-01 고도화 최종판) 추출

원천: `TPC MES 설계서 모음/★6 SF-TD3 화면설계서.pdf` (36화면 · 2024 고도화 · **도입기업 검토서명 = 하헌**).
용도: **C군(매일 기록)·M1 입고·POP 계열의 세부 문법 사전** — 19번 3템플릿과 충돌 없음, C 템플릿의 속을 채우는 재료.

## 1. 현장 화면 6문법 (C군·M1 이식 재료)

1. 🔁 **현장 메인 = 큰 컬러 타일 그리드** — 주작업([작업관리 START] 대형 주황 버튼) + 기능별 아이콘 타일(자재입하·수입검사·SPC자주…). 터치 지향·계층 없음. → M1 원버튼 사진함·현장 랜딩의 선례(우리 원버튼이 이 문법의 극단 단순화).
2. 🆕 **스캔 우선 입력**(투입LOT등록): 화면 최상단 = "LOT (SCAN)" 입력창 하나 — 스캔하면 좌측 내역 그리드에 쌓이고, **우측에 검사항목 체크가 병렬**(투입과 검사확인이 한 화면). → M2 공정 사진 체인·투입 기록 화면의 원형.
3. 🆕 **우측 세로 액션 패널**(라벨출력): 좌측 = 기록 그리드(제품 규격+검사일보), 우측 고정 = 수량 입력+대형 버튼 스택([라벨출력][불량등록][재출력][닫기]). **기록과 출력(행동)이 한 화면** — C 템플릿 우측 패널의 "행동 버튼 스택" 문법.
4. 🆕 **단일목적 모달**(라벨 재출력): 명령 1개 = 화면 1개 — LOT 입력 → 품번·품명·수량 **자동 표시(읽기전용 회색)** → 대형 실행 버튼 1개. 값을 다시 치게 하지 않는다. → 우리 확인형 액션(비번 재설정·완료 확정)의 문법.
5. 🆕 **3구획 세로 스택**(작업일보관리): ①생산 제품 규격 ②생산품 검사일보(용접조건: 파워·전압·전류·주파수·속도) ③비가동 내역 — 구획마다 우상단 [추가][저장]. **하루치 기록이 한 화면에서 완결** → "오늘 기록"(사장님 픽 대기) 화면의 실증 선례.
6. 🔁 **스캔→체크→저장 동선**(자재출고): 좌(대상 선택)|우(스캔 목록) + [체크][체크해제][저장] — 확인은 체크로, 입력은 스캔으로.

## 2. 관리자 그리드 5규약 (B·C군 그리드 문법)

1. 🔁 **툴바 고정 순서**: 초기화·조회·추가·저장·삭제·엑셀·인쇄·닫기 — 전 화면 동일 위치(우리 CardShell 액션 영역 순서 규범으로 채택).
2. 🆕 **필수 입력 계약**: 컬럼명 앞 `*` + 미입력 시 **경고창 + 저장 제한** — 전 화면 공통 문구까지 동일. (우리 REQUIRED_FIELDS 서버 검증의 화면측 짝 — C군 폼에 * 표기 통일 채택)
3. 🔁 **마스터-디테일 2패널**: 검사SPEC(좌 품번 | 우 항목), 품질검사내역(좌 내역 | 우 시료 1~5 측정값+판정) — 템플릿 C 그 자체. **시료 컬럼 1~5 가로 배치**가 검사 상세의 표준형(insp_record_value 렌더 문법).
4. 🆕 **REVISION 일자**(검사SPEC 등록 헤더): 스펙 개정일이 화면 1급 요소 — ★8 DB 대조 시 `insp_spec` 개정 이력 필드 여부 §0.5 질의 예정.
5. 🔁 **기간+품번 필터 행**이 그리드 위 고정 — B 템플릿 검색 밴드와 동형.

## 3. 모니터링 3형 (A군·TV 현황판 후보 — W4 후)

- 전체라인: 설비 카드(상태색 헤더 가동=녹/비가동=회 + 품번 대형 + 지시일/지시량/실적/불량/작업자) — 우리 매트릭스와 상보(설비축 vs 사람축).
- 공정별: **다크 배경 + 도넛 게이지(달성 % 대형) + 신호등 3색(비가동/대기/가동)** — TV 현황판 문법. 데일리Q TV 모드 후보.
- 설비별: 공장 레이아웃 맵에 색 타일. ⏭ (PLC 데이터 필요 — ③단 영역)

## 4. 판정 요약

- **신규 발견 6**: 스캔 우선·우측 액션 패널·단일목적 모달·3구획 스택·필수입력 계약(*+경고창+저장제한)·REVISION 일자.
- **검증(방향 일치) 5**: 큰 타일 현장 메인·툴바 순서·마스터-디테일·시료 가로 5열·필터 행. 12번 §0.9/19번 C 템플릿과 충돌 0.
- **무영향**: SCM 7화면(발주·라벨·명세서·재고·납품 — '안 한다' 영역, 목차 확인만)·설비 레이아웃 맵.
- **정정 필요 0** — 단 ★8 DB설계서 대조에서 insp_spec REVISION 필드 질의 1건 예약.

## 2. ⓒ 매트릭스 정렬 기준 — 확정

1. **1차 정렬 = 품번별 월 수불량**: `POP_JEPUM_SUBUL`에서 IOGBN='SO' 월별 QTY 합(품번 기준,
   최근 1~3개월). 견적 ⓒ의 "1차 정렬 = sqc_parts 검사 실측 상위"는 **보조(동률·수불 무실적
   품번의 후순위 정렬)로 강등**.
2. 공정축은 기존대로 routing_step 매핑 — 수불은 행(품번) 정렬만 담당.
3. 자재 레벨(하위코드×공정)이 필요해지면 `POP_JAJE_SUBUL` OT를 같은 방식으로 집계(이번
   범위 밖, 데이터는 검증됨).

## 1. Major 재봉합 — 갱신 폭주 (회신 §2)

- **원인 확정(코워크 의심 그대로)**: `useSeqGuard()`가 **매 렌더 새 객체를 반환** →
  `seq`를 deps 에 문 `load`가 렌더마다 재생성 → `useEffect(…, [load])` 재발사 →
  fetch→setState→재렌더의 자기 루프. ESC 정지(unmount 정리 정상)와 정확히 부합.
- **봉합 = 훅 근본 수정**(개별 화면 회피책 아님): `useSeqGuard` 반환 객체를 useRef 로
  **동일 참조 보장** — deps 에 그대로 넣어도 안전. 사고 경위는 asyncGuard.ts 주석에 명기.
- **전수 점검**: seq 를 deps 에 문 화면 12곳 확인 — 나머지는 effect 가 원시값 deps 라
  폭주는 전광판 단독(잠복 함정은 훅 수정으로 전체 소거).
